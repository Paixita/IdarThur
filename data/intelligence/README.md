# IdarThur Intelligence

Arquitectura inicial para convertir IdarThur en un asistente de viaje inteligente.

## Principios
- Detectar intención de viaje sin invadir la privacidad.
- Separar interés, lead y compra real.
- Priorizar fuentes confiables para información turística y noticias.
- Mantener a Yessel como interfaz conversacional central.
- No modificar el proyecto IdarThur App desde este directorio.

## Agentes previstos
- Radar: señales de intención de viaje.
- Perfilador: preferencias y contexto del viajero.
- Comercial: ofertas y oportunidades de monetización.
- Recomendador: combinación de vuelos, hoteles, autos, eventos y productos.
- Noticias/Seguridad: impacto de acontecimientos sobre decisiones de viaje.
- Conocimiento: recuperación de información turística actualizada.
- Seguimiento: comunicaciones únicamente cuando el usuario lo autorice.

## Métricas
Distinguir siempre entre:
1. visita
2. interés
3. lead voluntario
4. clic de afiliado
5. conversión confirmada

Este directorio es la base documental inicial; la implementación funcional se hará después de auditar y probar cada flujo.
